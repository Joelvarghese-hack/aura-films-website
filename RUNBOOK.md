# Aura Films — Site Safety & Recovery Runbook

Everything you need at 2 AM when something looks broken. Read top to bottom once
now so it is familiar later.

Live site: https://aurafilms.netlify.app
Source code: https://github.com/Joelvarghese-hack/aura-films-website

---

## 1. The 4 keys (store these in a password manager today)

Whoever holds these 4 logins controls everything. Losing them is the only real
way to lose the site, so back them up in a password manager (Bitwarden is free):

1. **GitHub** — the source code, all history, and the GitHub Pages backup copy.
2. **Netlify** — hosting, the live deploy, one-click rollback, and the domain.
3. **Domain registrar** — once you buy `aurafilms.ca` (the company you buy it from).
4. **`itsaurafilms@gmail.com`** — receives contact-form enquiries and can reset
   the logins above.

Because there is **no `.gitignore` excluding assets**, every one of these is
committed to GitHub. You currently have copies in **3 places**: your computer,
GitHub, and the GitHub Pages mirror. The backup script below adds a 4th that is
not tied to any account.

## 3. Make a backup you control (do this monthly + before big changes)

```
node backup.mjs
```

This writes two files into `backups/` (which is git-ignored, so it never bloats
the repo):

- **`aura-films-site-<date>.zip`** (~26 MB) — every current file, browsable in any
  unzip tool. **Drag this into Google Drive or onto a USB drive.** This is the one
  that matters.
- **`aura-films-full-<date>.bundle`** — the whole repo with full history in one
  file. Heavier; keep it if you have room.

**The 3-2-1 rule:** 3 copies, on 2 kinds of storage, 1 of them off-site.
You already have GitHub; the ZIP on Google Drive + a USB drive completes it.

> Photographers' note: a client's wedding/maternity photos are irreplaceable.
> Always keep the **full-resolution master files** in Drive/an external drive in
> addition to whatever is on the website.

## 4. If something breaks — pick the scenario

### A. A change made the live site look wrong or broke it
**Netlify one-click rollback (no code, ~60 seconds) — this is your 2 AM button.**
1. Go to https://app.netlify.com → your site → **Deploys**.
2. Find the last deploy from before the problem.
3. Click it → **Publish deploy**. The site is restored instantly.

### B. Netlify itself is down (rare)
- The **GitHub Pages copy** is still live as a fallback, and nothing is lost.
- Wait out the outage (check https://www.netlifystatus.com), or temporarily point
  the domain at GitHub Pages.

### C. Contact-form enquiries stopped arriving
- The form uses **Web3Forms**. First, confirm the access key is verified (check
  `itsaurafilms@gmail.com` for the verification email). **Until that is verified,
  enquiries may not deliver — this is the one live risk to fix first.**
- The footer always shows the email + phone as a manual fallback, so clients can
  still reach you even if the form fails.

### D. The whole project is gone (laptop died, account lost)
Restore from any backup:
```
# from the full-history bundle:
git clone "backups/aura-films-full-<date>.bundle" aura-films-restored

# or just unzip aura-films-site-<date>.zip to get all the files back

# or re-clone from GitHub:
git clone https://github.com/Joelvarghese-hack/aura-films-website.git
```
Then in Netlify, point a new site at the restored GitHub repo and redeploy.

### E. Restore one specific past version
Every commit is a restore point. Named launch snapshot: tag `v1.0-launch`.
```
git checkout v1.0-launch    # view the launch state
```

## 5. Early-warning setup (5 minutes, do once — so you find out fast)

- **Uptime alarm:** sign up at https://uptimerobot.com (free), add
  `https://aurafilms.netlify.app`, alert if down for 5 min. Emails/texts you.
- **Deploy alerts:** Netlify → Site settings → Notifications → email on failed deploy.
- **Verify the Web3Forms key** (scenario C) so the form actually delivers.

## 6. How the site is built (so a future you isn't lost)

The 6 pages in `redesign/` are **generated** — do not hand-edit the `.html`.
Edit the source and regenerate:
```
cd redesign
node gen.mjs        # rebuilds all 6 HTML pages from gen.mjs
```
Then commit and push to **both** branches (Netlify watches `claude/priceless-wilson`,
GitHub Pages serves `main`):
```
git add -A && git commit -m "your message"
git push origin HEAD:claude/priceless-wilson
git push origin HEAD:main
```
